# Processing Examples & Sketches

Una colección organizada de sketches y prácticas desarrolladas en Processing para explorar conceptos fundamentales de programación creativa, matemáticas aplicadas y renderizado visual.

Este repositorio recopila ejercicios clave divididos por temáticas fundamentales como el manejo de datos, vistas en tres dimensiones y teoría del color.

## 🚀 Contenido del Repositorio

El proyecto se estructura en las siguientes categorías visuales y técnicas:

### 📊 Arrays (Arreglos)
*   **Array:** Uso básico de arreglos unidimensionales para almacenar y manipular datos lineales.
*   **Array 2D:** Matrices bidimensionales aplicadas a la renderización de patrones y mallas de puntos.
*   **Array Objects:** Estructuras de datos complejas que contienen colecciones de objetos interactivos independientes.

### 🎥 Camera (Cámara y Espacio 3D)
*   **Move Eye:** Manipulación de la posición y el punto de vista del observador en un entorno tridimensional.
*   **Orthographic:** Renderizado con proyección ortogonal para eliminar la perspectiva y mantener proporciones reales.
*   **Perspective:** Configuración de cámaras con perspectiva cónica clásica para simular profundidad espacial profunda.

### 🎨 Color (Espacios de Color y Gradientes)
*   **Brightness / Saturation / Hue:** Control y desglose de las propiedades físicas del color usando los modos RGB y HSB.
*   **Color Variables:** Declaración, almacenamiento estático y dinámico de variables de color.
*   **Linear & Radial Gradient:** Algoritmos matemáticos de interpolación para crear transiciones suaves de color en líneas y círculos.
*   **Relativity:** Estudio e implementación de contrastes cromáticos y percepción visual relativa de Joseph Albers.
